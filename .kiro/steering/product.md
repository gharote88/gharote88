# Product: Marathi Learning App

A gamified, multi-platform language learning app for Marathi (मराठी शिका — Learn Marathi).

## Purpose
Help learners of all ages acquire Marathi through structured lessons, speaking, writing, reading, quizzes, mini-games, and cultural content.

## Key Features
- **Lessons & Phrases** — leveled content (beginner/intermediate/advanced) with transliteration and audio
- **Speaking** — speech recognition and pronunciation scoring via Google Speech API
- **Writing** — character tracing with stroke-order validation (vowels, consonants, conjuncts)
- **Reading** — passages with vocabulary and comprehension questions
- **Quizzes** — multiple-choice, fill-blank, match-pair, speak-answer
- **Mini-Games** — word scramble, phrase builder, audio matching, rapid fire, reading speed race, character tracing race
- **Story Mode** — interactive narrative chapters (dialogue, read sign, write note, mixed scenes)
- **Gamification** — XP, levels, streaks, badges, daily challenges, weekly leaderboard, avatar customization
- **Cultural Facts** — Marathi history, literature, culture, food, nature, festivals trivia
- **Parent/Child Accounts** — parents can link and monitor child learner accounts

## Target Audience
Children and adults learning Marathi; parents monitoring child progress.

## Platforms
- Mobile (iOS & Android) via Expo/React Native
- Web (React + Vite PWA)
- Admin/backend via Vercel Serverless Functions (`api/`)
